# Trident Public School — SVG Icon Pack

This package contains vector SVG redraws of the visible interface icons in the supplied screenshot.

Included:
- Header: phone, email, location, search
- Hero/navigation: left/right arrows
- Feature strip: laptop, people, bus, lotus, laboratory flask
- About/statistics: school board, ratio, years/calendar, commitment/check
- Academics: open book, graduation cap, lightbulb, trophy
- Facilities: classroom, science lab, library, transport
- Footer/social: Facebook, Instagram, X/Twitter, YouTube, LinkedIn
- Contact/newsletter: location, phone, email, clock, send
- Brand mark approximation
- sprite.svg containing all symbols

Notes:
- The source image is a raster screenshot, so these are clean vector redraws based on the visible shapes; they are not extracted original source SVGs.
- Colors/strokes are editable directly in each SVG.
- Files use a 64×64 viewBox for easy scaling.
